# Clínica Áurea — demonstração

Landing page demonstrativa para prospecção de clínicas odontológicas.

> Todos os nomes, contatos, endereço e textos institucionais são demonstrativos/fictícios. As fotografias são imagens ilustrativas externas do Unsplash e devem ser substituídas por fotos autorizadas do cliente em um projeto real.

## Estrutura
- HTML semântico
- CSS responsivo, mobile-first na adaptação
- JavaScript mínimo para navegação móvel
- CTA de WhatsApp demonstrativo
- SEO básico e acessibilidade

## Publicação
Compatível com GitHub Pages por ser um site estático.
