# Áurea Odontologia — Demo

Landing page demonstrativa criada para prospecção de clínicas odontológicas e apresentação de trabalho de desenvolvimento web.

**Demo:** https://viniciosix.github.io/demo-clinica/

## Objetivo

Mostrar como uma clínica odontológica pode ter uma presença digital própria, moderna e focada em conversão, com navegação simples, boa experiência no celular e acesso rápido ao agendamento.

## Destaques

- layout responsivo e mobile-first;
- identidade visual própria;
- CTAs para agendamento e WhatsApp;
- navegação leve em HTML, CSS e JavaScript;
- estrutura preparada para integração com ferramentas de agendamento;
- SEO e acessibilidade básicos;
- marca-d'água de demonstração para apresentação comercial.

## Aviso

Este é um projeto demonstrativo. Nome, contatos e demais informações da clínica são fictícios e devem ser substituídos pelos dados reais e autorizados do cliente antes de qualquer publicação oficial.
